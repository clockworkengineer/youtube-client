# YouTube Client

A lightweight Rust-based YouTube client consisting of a backend library, a command-line interface, and a native GUI application.

## Documentation

- [Google OAuth2 Credentials Setup Guide](docs/google_setup.md)
- [Video Playback Configuration Guide](docs/video_playback.md)

## Features

- OAuth2 Authentication with Google APIs.
- Browse subscriptions and channel videos.
- Native GUI built with `egui` and `eframe`.
- Direct video streaming via `mpv`, `vlc`, or default browser fallback.
